# Pioneer Delivery Documentation

The accepted documentation baseline is consolidated into:

- [SRS v1.0](SRS-Pioneer-Delivery-v1.0.md) — requirements and acceptance criteria.
- [SDS v1.0](SDS-Pioneer-Delivery-v1.0.md) — approved design, interfaces, algorithms, and verification strategy.

Earlier parent/task SRS files and SDS v0.3 have been removed as deprecated. The v1.0 documents are the current requirements/design authority, with the style guide retained as supporting implementation guidance.
